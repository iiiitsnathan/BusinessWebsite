## 2024-11-09 - Navigation Accessibility\n**Learning:** Interactive or expanding components (e.g., mobile menus, accordions) need dynamic `aria-expanded` bound to their boolean state, pair it with an explanatory `aria-label` or conditionally applied `aria-controls={isOpen ? id : undefined}` pointing to the content's `id`, explicitly style focus states for keyboard users (e.g., `focus-visible:outline-none focus-visible:ring-2`), and hide decorative icons with `aria-hidden="true"`.\n**Action:** Apply these patterns to the mobile navigation menu button and container in Navigation.tsx.

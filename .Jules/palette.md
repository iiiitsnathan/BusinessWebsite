## 2025-03-01 - Mobile Menu Toggle Accessibility Pattern
**Learning:** In Next.js/React applications with conditional rendering for expanding mobile menus, applying `useId` provides an elegant and stable ID generation strategy. This guarantees the toggle button's `aria-controls` reliably maps to the rendered mobile menu container's ID, even when the menu is hidden (resulting in `aria-controls={undefined}`). Additionally, ensuring explicit focus states using tailwind classes (e.g., `focus-visible:ring-2 focus-visible:outline-none`) and setting `aria-hidden="true"` on decorative icons provides optimal screen reader handling and keyboard navigation for responsive mobile menus.
**Action:** When implementing mobile menus or accordions across this app, consistently use this robust combination: `useId()` for `aria-controls` and `id`, bind `aria-expanded` to state, hide Lucide icons with `aria-hidden="true"`, and apply `focus-visible` styles to interactive triggers.

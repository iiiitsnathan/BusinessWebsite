## 2024-06-18 - Mobile Menu ARIA Accessibility
**Learning:** When building responsive navigation menus that switch between desktop and mobile modes, the mobile toggle button (`<button>`) requires proper ARIA attributes to be screen-reader accessible. Using `useId()` correctly associates the `aria-controls` on the toggle button with the `id` of the menu container. Additionally, explicitly adding `aria-expanded={boolean}` on the toggle button and `aria-hidden="true"` to decorative icons like the Lucide `Menu` and `X` is essential so that assistive technologies read the button state and label correctly without double-announcing the icons.
**Action:** Always pair `aria-expanded` and `aria-controls` with dynamic expanding containers using `useId()`, and ensure keyboard users have visual focus indicators (`focus-visible:ring-2`) and screen reader users aren't confused by missing accessible labels or visible icons.

## 2023-11-10 - ARIA bindings for expanding UI components
**Learning:** For dynamic components like mobile menus, screen readers need to know both the state (open/closed) and what content is being controlled. Without `aria-expanded` and an `id`-linked `aria-controls`, the visual action of opening a menu remains invisible to screen readers, leaving users trapped or unaware. Also, native semantic focus indicators (`focus-visible`) must be explicitly declared for custom styled elements so keyboard-only users know when they have successfully navigated to the control.
**Action:** When implementing responsive navigations or custom accordions, always generate a unique ID using `React.useId()`, bind `aria-expanded` to the boolean state, assign `aria-controls` (only if the element is in the DOM), explicitly define focus styles, and silence decorative SVG icons with `aria-hidden="true"`.
